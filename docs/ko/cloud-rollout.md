# 전체 데이터 클라우드 전환

## 승인된 방향

- 기존 homecook의 모든 레시피, 사진, 팬트리, 식단, 장보기, 요리 기록과 주문을 Supabase에 저장합니다.
- 남편과 아내는 각각 고정 사용자이며 역할과 인증 코드로 어떤 기기에서든 로그인합니다.
- 남편이 앱에서 아내 코드를 정하고 변경합니다. 로그인 코드는 자동 만료되지 않습니다.
- 두 사람 모두 주문과 접수를 포함한 일반 기능을 사용합니다. 사용자 관리는 남편만 가능합니다.
- 새 기기로 로그인해도 기존 기기 연결을 유지합니다.
- 기존 사용자 데이터가 없으므로 로컬 데이터 이전은 구현하지 않습니다.

## 현재 진행 상태

첫 단계인 서버 테이블과 세션 접근 제어 기반을 추가했습니다.
아직 운영 서버에 적용하지 않았으며 기존 화면은 이전 연결 방식을 사용합니다.
코드 로그인 화면과 모든 데이터의 자동 서버 저장은 이후 단계에서 구현합니다.

## 이후 순서

1. 최초 관리자 설정과 코드 로그인, 코드 변경
2. 레시피, 사진, 재료의 서버 저장
3. 팬트리, 식단, 장보기, 요리 기록의 서버 저장
4. 공동 주문 처리와 조리 이어하기
5. 기기 간 동기화, 개인 기기 캐시, 공용 기기 모드
6. 여러 기기 알림, 전체 내보내기, 실제 아이폰 검증

각 단계는 PR 검토와 병합 후 다음 단계로 진행합니다.
공용 교육장 PC에는 운영 인증 정보와 비밀값을 저장하지 않습니다.
상세 구현 기준은 [전체 설계](../cloud-rollout.md)에 있습니다.
